New to PolarFire SoC? Start here

A suggested learning path, from documentation to a running Linux system.

Step 1Read the docsBoard guides, boot flow, HSS, and Linux how-tos. Step 2Build a reference designIcicle Kit, Discovery Kit, or Video Kit Libero designs. Step 3Boot with HSSHart Software Services: zeroth-stage boot loader and services. Step 4Run bare-metal examplesDriver examples for the MSS peripherals. Step 5Build LinuxYocto (meta-mchp) or Buildroot external tree. Step 6Accelerate with HLSSmartHLS examples: C++ to FPGA hardware. Step 7Add Edge AIVectorBlox SDK: run AI/ML models without reprogramming the FPGA.

Using a non-SoC PolarFire, RTG4, or SmartFusion2 device? Start with the Mi-V soft RISC-V designs and examples.
